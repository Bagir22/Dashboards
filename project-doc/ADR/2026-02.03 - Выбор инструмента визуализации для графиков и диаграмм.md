**Дата:** 24 февраля 2026 г.

**Статус:** Принято

**Контекст:**

В рамках разработки приложения на Angular нам необходим инструмент для визуализации данных, который будет использоваться в двух ключевых частях системы: в режиме конструктора для создания дашбордов и в режиме просмотра для конечных пользователей.

Требования к инструменту:
- возможность выбора различных типов визуализации (графики, диаграммы, таблицы);
- настройка источников данных для каждого виджета;
- гибкая настройка внешнего вида и фильтров;
- поддержка интерактивности (применение фильтров, экспорт данных);

**Рассмотренные варианты:**

- Проприетарные BI-решения (Tableau, Power BI Embedded): Мощные корпоративные продукты с широкой функциональностью. Минусы: высокие затраты на лицензирование и сложная модель ценообразования при масштабировании.
- Самописные решения на базе библиотек (ECharts, D3.js, Highcharts, chart.js): Максимальная гибкость и полный контроль над кодом. Минусы: высокие трудозатраты на разработку бэкенда для управления виджетами, хранения метаданных, обработки запросов к данным и разграничения доступа.
- Metabase Open Source Edition: Open-source BI-инструмент с готовым веб-интерфейсом для администраторов, простотой установки и поддержкой встраивания графиков.

**Решение:**

Выбран Metabase Open Source Edition в качестве инструмента для визуализации данных.

**Обоснование:**

- Отсутствие лицензионных отчислений: Бесплатная версия Metabase позволяет реализовать требуемый функционал без ежемесячной платы за каждого пользователя или просмотр, что важно для MVP и снижает финансовую нагрузку на проект.
- Готовый функционал "из коробки": Metabase уже имеет встроенные механизмы для подключения к базам данных, создания графиков, настройки фильтров и управления доступом. Это избавляет от необходимости разрабатывать эти сложные компоненты самостоятельно.
- Простота встраивания: Metabase предоставляет удобные механизмы для встраивания отдельных графиков и дашбордов во внешние приложения через iframe или SDK.
- Сообщество и документация: Metabase имеет большое сообщество и подробную документацию, что упрощает решение возникающих проблем.

**Последствия:**

- В инфраструктуре проекта появляется еще один компонент - сервер Metabase, требующий развертывания.
- Функционал виджетов будет частично "завязан" на возможности Metabase; если потребуется уникальный тип визуализации, не поддерживаемый Metabase, его реализация будет затруднена.
- Необходимо предусмотреть синхронизацию пользователей и прав доступа между основным приложением и Metabase.
