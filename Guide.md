# Инструкция по развертыванию проекта

Данное руководство описывает процессы запуска,
системы, состоящей из **PostgreSQL**, **Metabase**, **.NET Backend** и **Angular** фронтенда.

---

## Системные требования и зависимости

### Программные зависимости
* **Docker & Docker Compose** (обязательно для контейнеризации БД и Metabase)
* **Node.js v20+** (для локального запуска и сборки фронтенда)
* **.NET 8 SDK** (для локального запуска и сборки бэкенда)
* **Файл `.env`** в корне проекта с актуальными секретами и портами

### Поддерживаемые ОС
* **Windows** (10/11, Server 2019+)
* **Linux** (включая **Astra Linux**, Ubuntu 22.04+, Debian 11+)

### Аппаратные требования (Минимальные)

#### 1. Сервер приложений
* **Процессор:** Intel(R) Xeon(R) Gold 6140 CPU @ 2.30GHz (минимум **6 виртуальных ядер**)
* **Оперативная память (RAM):** 32 ГБ
* **Дисковая подсистема:**
    * Системный диск: **50 ГБ**
    * Диск для данных: **256 ГБ**

#### 2. Сервер хранения данных (БД)
* **Процессор:** Intel(R) Xeon(R) Gold 6136 CPU @ 3.00GHz (минимум **12 виртуальных ядер**)
* **Оперативная память (RAM):** 64 ГБ
* **Дисковая подсистема:**
    * Системный диск: **50 ГБ**
    * Диск для данных: **512 ГБ**

## Сценарий 1: Полный запуск в Docker

Используется для быстрого развертывания всей инфраструктуры.

### 1. Запуск всех сервисов
#### Сборка образов и запуск в фоновом режиме
```
docker-compose up -d --build
```

### 2. Проверка состояния
```
docker-compose ps
```

#### Просмотр логов конкретного сервиса (например, Metabase)
```
docker-compose logs -f metabase
```

### 3. Остановка и очистка
#### Остановка контейнеров
```
docker-compose down
```

#### Полная очистка контейнеров
```
docker-compose down -v
```

## Сценарий 2: Гибридный запуск 
В этом режиме база данных и Metabase работают в Docker, а приложения запускаются локально для быстрой отладки.

### 1. Подготовка инфраструктуры
```
docker-compose up -d db metabase
```


### 2. Запуск Backend (.NET)
Откройте терминал в папке бэкенда:

```
cd backend/Dashboards
dotnet watch run
```

### 3. Запуск Frontend (Angular)
Откройте терминал в папке frontend:

#### Установка зависимостей
```
npm i
```

#### Запуск Host App (Порт 4200)
```
npx ng serve host --port 4200
```

#### Запуск Dashboards App
```
npx ng serve dashboards --port 4201
```
